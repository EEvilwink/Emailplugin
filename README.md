# Ezmail

Minecraft / **Paper 26.2** 服务器插件：给玩家一个"邮箱"，让玩家可以互相留言。留言不会直接出现在聊天栏里，
而是以"未读数量"的形式提示，玩家点击聊天栏的文字（或输入指令）打开箱子风格的界面，再点击其中的留言才会把内容输出到聊天栏。

## 功能

- `/ezmail send <玩家> <内容>`（可简写为 `/em send ...`）给其他玩家留言，对方在线或离线都可以。
- 收到留言时只在聊天栏提示未读数量，**不会**直接显示内容。
- 点击聊天栏里的提示文字，或输入 `/em inbox`，打开箱子风格的收件箱：
  - 未读 / 已读留言用不同物品、不同颜色区分（可在配置里自定义）。
  - 物品的描述里显示发送者、发送时间、已读状态；已读留言还会显示自动删除倒计时。
  - 界面里不显示留言内容，点击物品后才会把内容输出到聊天栏，同时该留言变为已读。
  - 留言数量超过一页时可以翻页。
- `/em sent` 打开发送界面：查看自己发出的留言、对方是否已读；左键查看内容，右键删除留言。
  删除后收件人就不会再收到这条留言。
- 玩家上线时如果存在未读留言会收到提示，之后每隔一段时间再次提醒（可配置），提示带音效。
- `/em admin` 打开管理员菜单：查看服务器上所有未读留言和已读但未删除的留言，
  显示发送者、接收者、发送时间，已读留言额外显示待删除时间，同样支持翻页。
- 已读留言会在配置的时间后自动删除；发送数量、单人数量、冷却时间都可以在配置里限制，
  并支持按权限组配置更高的额度。

## 指令

| 指令 | 说明 | 权限 |
| --- | --- | --- |
| `/ezmail send <玩家> <内容>` | 给玩家留言 | `ezmail.send` |
| `/ezmail inbox` | 打开收件箱 | `ezmail.inbox` |
| `/ezmail sent` | 打开发送界面 | `ezmail.sent` |
| `/ezmail admin` | 打开管理员菜单 | `ezmail.admin` |
| `/ezmail reload` | 重载配置 | `ezmail.reload` |
| `/ezmail help` | 显示帮助 | - |

主指令为 `/ezmail`，别名 `/em`。

## 权限

| 权限 | 默认 | 说明 |
| --- | --- | --- |
| `ezmail.send` | 所有人 | 允许发送留言 |
| `ezmail.inbox` | 所有人 | 允许打开收件箱 |
| `ezmail.sent` | 所有人 | 允许查看已发送的留言 |
| `ezmail.admin` | OP | 允许打开管理员菜单 |
| `ezmail.reload` | OP | 允许重载配置 |
| `ezmail.bypass.cooldown` | OP | 无视发送冷却 |
| `ezmail.bypass.limit` | OP | 无视发送数量限制 |
| `ezmail.limit.<组名>` | 否 | 使用配置中对应权限组的额度（默认提供 `vip`、`staff`） |

## 配置文件

配置文件位于 `plugins/Ezmail/config.yml`，修改后执行 `/ezmail reload` 生效（已打开的界面会自动关闭，重新打开即可）。

- `settings`：是否允许给自己留言、是否允许给从未上线的名字留言、留言长度上限、发送冷却、
  已读留言自动删除时间、时间格式、聊天栏点击的实现方式。
- `limits`：默认与按权限组的发送数量限制（`total` 总条数、`per-recipient` 对单个玩家的条数）。
- `reminder`：上线提醒开关、定时提醒间隔与提醒音效。
- `sounds`：发送、读取、删除、打开界面、出错时的音效。
- `gui`：三种界面的标题、行数、信息物品、未读物品、已读物品的材质 / 名称 / 描述，以及翻页、关闭、填充物品。
  例如把未读留言改为红色染料、已读留言改为绿色染料（默认即如此）。
- `messages`：所有提示文本、留言输出格式、状态文字、倒计时单位、帮助信息。

文本支持 `&` 颜色代码（如 `&c红色`）和 MiniMessage（如 `<red>`）；同一段文本请只用其中一种写法。
文本中的 `{xxx}` 是占位符，例如 `{player_sender}`、`{email}`、`{count}`、`{countdown}`、`{page}`、`{pages}` 等。

留言数据保存在 `plugins/Ezmail/mails.yml`，每 30 秒自动保存一次，关服时也会保存。

## 构建

```bash
./gradlew build        # Windows: gradlew.bat build
```

生成的插件位于 `build/libs/Ezmail-1.0.0.jar`，放入服务器的 `plugins/` 目录即可。

需要 Java 25 与 Paper 26.2（`paper-api:26.2.build.+`）。
